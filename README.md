# Machine learning exam study site

https://eldarush.github.io/machine-learning-exams/

Static Hebrew RTL study site with exam practice, source previews, course summaries and historical A/B comparisons.

This publication contains only browser assets, public study data and source copies. Every question preview is pre-rendered: no Python server or API is required on GitHub Pages. Copy prompts use public links rather than machine-local paths. Original page numbering is preserved in sanitized source copies.

Build from the maintained local workspace with `python tools/export_pages.py`; all local originals stay unchanged. The published source SHA-256 values describe the public copies.
